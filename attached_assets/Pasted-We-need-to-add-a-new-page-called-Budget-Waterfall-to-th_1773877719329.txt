Build a waterfall chart that explains the variance from Budget NOI to Actual NOI for the selected month.

The chart should start with:
- Budget NOI

Then show individual favorable/unfavorable variance contributions by line item.

Then end with:
- Actual NOI

This should visually bridge:
Budget NOI → line item variances → Actual NOI

--------------------------------------------------

If a category is missing or zero for the selected month, omit it from the chart unless we explicitly want to show zero-value categories.

--------------------------------------------------
CALCULATION LOGIC
--------------------------------------------------

For the selected month:

Budget NOI = Budget Effective Gross Income - Budget Operating Expenses

Actual NOI = Actual Effective Gross Income - Actual Operating Expenses

Each waterfall step should represent the variance contribution of that line item versus budget.

Variance logic:
- Favorable variance should move the chart in the positive direction
- Unfavorable variance should move the chart in the negative direction

Income logic:
- Actual above Budget = favorable
- Actual below Budget = unfavorable

Expense logic:
- Actual below Budget = favorable
- Actual above Budget = unfavorable

Normalize the variance signs so the waterfall tells a clean story from Budget NOI to Actual NOI.

The sum of all variance steps must reconcile exactly:

Budget NOI + sum(all normalized variance steps) = Actual NOI

This reconciliation is critical.
