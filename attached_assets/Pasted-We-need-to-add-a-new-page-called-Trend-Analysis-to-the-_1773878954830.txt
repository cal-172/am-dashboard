--------------------------------------------------
FAVORABILITY LOGIC
--------------------------------------------------

Bar color must be based on whether Actual is favorable or unfavorable relative to Budget.

For revenue/income-type categories:
- Actual > Budget = favorable = green
- Actual < Budget = unfavorable = red

For expense-type categories:
- Actual < Budget = favorable = green
- Actual > Budget = unfavorable = red

For NOI / cash flow style metrics:
- Actual > Budget = favorable = green
- Actual < Budget = unfavorable = red

Use the category type to determine the correct favorable/unfavorable rule.
